YouTube Automation Agent

This application renders and uploads travel-destination Shorts to the Latent Space Clips YouTube channel. It is operated solely by the channel owner and is not offered as a public service.

What it does

  • Collects licence-tagged stock footage and free Creative Commons music.
  • Renders vertical 9:16 Shorts locally with FFmpeg.
  • Uploads finished Shorts to the owner's YouTube channel through the YouTube Data API.
  • Reads the channel's own analytics and comments to plan future videos.

Data and privacy

The tool accesses only the owner's YouTube channel and its own analytics. OAuth tokens are kept in a local configuration file and as encrypted GitHub Actions secrets. Data is never sold or shared with advertisers. See the Privacy Policy for details.
