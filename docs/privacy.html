Privacy Policy

Effective October 27, 2026

YouTube Automation Agent is a personal, owner-operated tool that renders and uploads travel Shorts to the Latent Space Clips YouTube channel. This policy explains what Google user data the tool accesses, how it is used and stored, and the controls available to the channel owner.

1. Google user data accessed

With the channel owner's authorization, the tool uses these Google API scopes:

  • YouTube Data API — read the owner's channel, videos, and comments, and upload videos and thumbnails to that channel.
  • YouTube Analytics API — read the owner's channel analytics to understand which videos perform well.
  • OAuth 2.0 credentials — an access token and refresh token used only to call these APIs on the owner's behalf.

The tool does not access Gmail, Google Drive, Contacts, Calendar, or any other Google service.

2. How the data is used

  • To render, upload, and manage videos on the owner's own YouTube channel.
  • To review the channel's own analytics and comments when choosing future video topics and improving descriptions.
  • No data is used for advertising, profiling, or training third-party models.

3. Storage and security

  • OAuth tokens are stored in a local config/tokens.json file with owner-only permissions and, for scheduled cloud runs, as encrypted GitHub Actions secrets.
  • Rendered videos and analytics snapshots are stored locally on the owner's computer or as short-lived GitHub Actions artifacts.
  • Access is limited to the channel owner; the tool is not a multi-user service.

4. Sharing

Google user data is not sold, rented, or shared with advertisers or data brokers. The tool sends data only to Google APIs (to upload videos and read the owner's analytics) and to GitHub (to run scheduled jobs and store encrypted secrets). Stock footage is sourced from Pixabay under its content licence; no Google user data is sent there.

5. Retention and deletion

OAuth tokens remain valid until the owner revokes access or deletes them. Analytics snapshots and rendered media are kept locally for as long as the owner needs them. To delete stored data or revoke access:

  • Revoke the app at myaccount.google.com/permissions.
  • Delete config/tokens.json and the GitHub Actions secrets in the repository settings.
  • Email the contact below to request deletion of any remaining local data.

6. Limited Use

The tool's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the features described above.

7. Changes

Material changes to this policy will be posted on this page with a new effective date.
